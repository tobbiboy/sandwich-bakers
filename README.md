# Sandwich Bakers

A responsive, multi-page website concept for a neighborhood bakery serving street sandwiches, sweet treats, and savory bites. Built with plain HTML, CSS, and JavaScript.

## Preview

[View the live site](https://tobbiboy.github.io/sandwich-bakers/).

Open [`index.html`](./index.html) in a browser, or open the project folder in Visual Studio Code and use Live Server.

## Pages

- **Home** — introduction and featured offerings
- **Our Story** — the bakery’s story and occasions
- **Our Promise** — the experience and values
- **Menu** — sandwiches, bakes, savory bites, and sharing boxes
- **Catering** — group orders and event options
- **Order & Contact** — enquiry form and contact details

## Built with

- HTML
- CSS, including responsive layouts and a shared green-and-cream design system
- Vanilla JavaScript for mobile navigation and the demo enquiry form

## Run locally

No build tools or package installation are required.

1. Clone or download this repository.
2. Open `index.html` in a browser, or open the project folder in Visual Studio Code and start Live Server.

The homepage hero features [`image4.jpeg`](./image4.jpeg), and the order page highlights the packaged loaf in [`assets/natures-loaf.png`](./assets/natures-loaf.png). The menu and story pages also use the supplied bakery and bread photography.

## Deploy with GitHub Pages

1. Push the project to a GitHub repository.
2. Open the repository’s **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder, then save.
5. When the deployment finishes, open the published URL shown in the Pages settings.

## Before using this as a live bakery site

- Replace the placeholder email address and location on the contact page.
- Add confirmed products, prices, availability, and ingredient/allergen information.
- Connect the enquiry form to a form service or backend. The current form is a front-end demo and does not send messages.
